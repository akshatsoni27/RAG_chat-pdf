Deep Learning — Notes
1. What is Deep Learning?

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers to learn complex patterns from data.

Traditional machine learning often requires humans to select and engineer useful features. Deep learning can automatically learn representations and features from raw data.

Deep learning is widely used in:

Image recognition
Speech recognition
Natural language processing
Recommendation systems
Autonomous vehicles
Medical image analysis
Generative AI
Computer vision
2. Artificial Neural Networks

A neural network is inspired by the structure of biological neurons.

A basic neural network consists of:

Input layer
Hidden layers
Output layer

Each neuron receives inputs, applies weights, adds a bias, and passes the result through an activation function.

The basic calculation is:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

where:

x = input
w = weight
b = bias
z = weighted sum

The activation function then determines the neuron's output.

3. Activation Functions

Activation functions introduce non-linearity into neural networks.

Common activation functions include:

ReLU

ReLU(x) = max(0, x)

ReLU is commonly used in hidden layers because it is computationally simple and helps neural networks learn complex patterns.

Sigmoid

The sigmoid function produces values between 0 and 1.

It is commonly used for binary classification output.

Tanh

Tanh produces values between -1 and 1.

It was commonly used in older neural network architectures and is still useful in some applications.

Softmax

Softmax converts a set of values into probabilities whose sum is 1.

It is commonly used for multi-class classification.

4. Forward Propagation

Forward propagation is the process of passing input data through the neural network to generate an output.

For example:

Input → Hidden Layer → Hidden Layer → Output

Each layer performs calculations using its weights, biases, and activation functions.

The final output represents the model's prediction.

5. Loss Function

A loss function measures how different the model's prediction is from the actual target.

The objective of training is to minimize the loss.

Common loss functions include:

Mean Squared Error (MSE)
Mean Absolute Error (MAE)
Binary Cross Entropy
Categorical Cross Entropy

For regression problems, MSE is commonly used.

For classification problems, cross-entropy loss is commonly used.

6. Backpropagation

Backpropagation is the process used to calculate how much each model parameter contributed to the prediction error.

The general process is:

Prediction → Calculate Loss → Calculate Gradients → Update Weights

The gradients are calculated using the chain rule of calculus.

Backpropagation allows the neural network to learn from its errors.

7. Gradient Descent

Gradient descent is an optimization algorithm used to minimize the loss function.

The model updates its parameters in the direction that reduces the loss.

A simplified update rule is:

new weight = old weight - learning rate × gradient

The learning rate controls how large each update is.

A learning rate that is too large can make training unstable, while a very small learning rate can make training extremely slow.

8. Epochs, Batch Size, and Iterations

An epoch means that the model has processed the entire training dataset once.

A batch is a smaller portion of the training dataset.

An iteration is one parameter update based on one batch.

For example, if a dataset contains 1,000 samples and the batch size is 100:

1 epoch = 1,000 samples processed
10 iterations = 1 epoch
9. Overfitting and Underfitting

Overfitting occurs when a model learns the training data too closely and performs poorly on unseen data.

Signs of overfitting:

Very high training accuracy
Significantly lower validation accuracy

Solutions include:

Dropout
Data augmentation
Regularization
Early stopping
More training data

Underfitting occurs when the model is too simple to learn the underlying patterns in the data.

10. Convolutional Neural Networks

CNNs are neural networks commonly used for image and computer vision tasks.

A CNN typically contains:

Convolution layers
Activation functions
Pooling layers
Fully connected layers

The convolution operation allows the network to detect features such as:

Edges
Shapes
Textures
Objects

CNNs are commonly used for:

Image classification
Object detection
Facial recognition
Medical image analysis
11. Recurrent Neural Networks

RNNs are designed to process sequential data.

They maintain information from previous steps, making them useful for sequences such as:

Text
Speech
Time series
Sensor data

A major limitation of traditional RNNs is the vanishing gradient problem.

12. LSTM and GRU

LSTM stands for Long Short-Term Memory.

LSTMs were developed to handle long-term dependencies better than traditional RNNs.

An LSTM contains gates that control information flow:

Forget gate
Input gate
Output gate

GRU stands for Gated Recurrent Unit.

GRUs are similar to LSTMs but have a simpler architecture and fewer gates.

13. Transformers

Transformers are neural network architectures designed primarily for processing sequential and contextual information.

They use self-attention to determine which parts of an input are important when processing another part.

Transformers are the foundation of many modern AI systems, including large language models.

Important components include:

Self-attention
Multi-head attention
Positional encoding
Feed-forward networks
Layer normalization

Transformers are widely used in:

Natural language processing
Machine translation
Text generation
Computer vision
Multimodal AI
14. Transfer Learning

Transfer learning involves taking a model that has already been trained on a large dataset and adapting it to a new task.

For example, a model trained on millions of images can be fine-tuned for medical image classification.

Advantages include:

Less training data required
Faster training
Better performance
Reduced computational cost
15. Fine-Tuning

Fine-tuning means continuing the training of a pretrained model on a specific dataset or task.

For example:

Pretrained LLM → Fine-tuning → Medical chatbot

Fine-tuning can adapt a model's behavior or knowledge to a particular domain.

16. Deep Learning Frameworks

Popular deep learning frameworks include:

PyTorch
TensorFlow
Keras
JAX

PyTorch is widely used in research and modern AI development.

17. Deep Learning vs Machine Learning
Machine Learning	Deep Learning
Often requires feature engineering	Learns features automatically
Can work well with smaller datasets	Often benefits from large datasets
Generally lower computational requirements	Usually higher computational requirements
Includes algorithms like Random Forest and SVM	Uses multi-layer neural networks
Often easier to interpret	Can be more difficult to interpret

Large models can learn patterns from enormous datasets and generate new content such as:

Text
Images
Audio
Video
Code
